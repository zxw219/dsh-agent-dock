# DSH 其他小天才们

当前日常模式是 **WorkBuddy 主窗口快捷入口**。点击 DSH 左侧 WorkBuddy，或管理卡片的“打开 WorkBuddy”，还原已运行的软件并把窗口放到当前显示器中央。不会读取对话列表、打开独立对话小窗或持续跟随 DSH。

## 使用

1. 手动启动 WorkBuddy。主窗口最小化或关闭到右下角托盘后，也可直接通过 DSH 入口还原，无需先点击托盘。
2. 在“其他小天才们”管理页添加 WorkBuddy，保存设置。
3. 点击左侧 WorkBuddy 或管理卡片“打开 WorkBuddy”。窗口自动居中，目标大小最高 1440×1000；屏幕较小时按可用区域缩小。
4. 使用完正常切换回 DSH。WorkBuddy 保持独立窗口，不会随切换自动隐藏或关闭。

环境为 Windows、PowerShell 7（`pwsh.exe` 在 PATH 中，也可设置 `DSH_PWSH_PATH`）。只操作已运行的 WorkBuddy，不会执行配置中的软件路径。存在多个无法区分的 WorkBuddy 窗口时会报错，请先关闭额外独立对话窗。窗口无法还原、越出可用区域或未取得前台焦点时会显示原因。

列表读取、演示对话、独立对话小窗和窗口跟随代码保留备用，但 WorkBuddy 日常界面已隐藏这些入口；既有本地设置不会删除。保留的高级模块测试不代表它们已重新投入日常使用。侧栏图标的旧健康逻辑不是持续运行状态监控。

不读取第三方数据库、登录令牌或私有接口，不同步聊天，不修改第三方软件文件。参考项目列于 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

## 配置和搜索

管理页仍可添加、排序、关闭或移除入口；关闭仅隐藏入口，保留设置。WorkBuddy 设置只显示智能体选择和入口开关，复杂设置收起备用。其他智能体暂保留原有本地预览。

“搜索本机智能体”通过 DSH 公开会话服务创建新对话并发送只读检查提示词。检查由该会话执行，先报告安装证据及路径，再由用户选择配置；不会自动扫描或启动其他软件。

`data/workbench.json` 保存智能体设置和演示标题，写入有版本检查。Android 配置单独保存于 `data/android.json`。运行时 data 不上传仓库、不包含在打包文件列表。

## Android 备用页

管理页的 Android 模拟器标签保留启动、打开页面、隐藏、停止、刷新和设备设置。进入管理页、点击 WorkBuddy 不会启动模拟器。Android 生命周期仍为此前原型，本次未调整。

默认 SDK 为 `%LOCALAPPDATA%\Android\Sdk`，可用 `ADB_PATH`、`EMULATOR_PATH` 覆盖。默认 AVD 为 `Pixel_Tablet`，serial 为 `emulator-5554`。

## 验证

运行 `node --test tests/*.test.mjs`。当前 49 项测试覆盖本地配置、路由保护、客户端流程及备用模块协议；新增测试确认 WorkBuddy 日常入口只调用 show-main，不请求 sidebar/open/viewport，并隐藏复杂界面、保留原配置。组件测试不代替真实点击验收。

本机真实 DSH 点击验收：管理卡片“打开 WorkBuddy”和左侧 WorkBuddy 入口均成功还原主窗口、切到前台，实际尺寸为 1440×1000；同时存在旧独立对话窗时，也通过主窗口结构标识选中了主窗口。此次不读取对话列表、不打开新对话小窗。另已从真实关闭到托盘的隐藏状态点击 DSH 左侧入口，确认原主窗口重新可见、取得前台且为 1440×1000。其他机器和多显示器缩放组合仍需各自验证。

不上传 Android SDK、AVD、系统镜像、账号或聊天记录。
